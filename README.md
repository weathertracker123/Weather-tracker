# Boston Weather Tracker

Live Boston weather with hourly temperature, precipitation and wind, National Weather Service warnings, Charles River flow (USGS gauge 01104500), and a satellite map of the Head of the Charles course with an animated wind overlay.

Live site: https://sammypars.github.io/Weather-tracker/

All data comes from free, keyless sources: Open-Meteo, api.weather.gov, USGS Water Services, and Esri/CARTO map tiles.
